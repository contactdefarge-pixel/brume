BRUME - réverbe stéréo + bruit
================================

WINDOWS (Ableton Live)
1. Copier le dossier "Brume.vst3" dans :
   C:\Program Files\Common Files\VST3\
2. Dans Ableton : Préférences > Plug-ins > activer "Utiliser les dossiers système VST3",
   puis cliquer sur "Rescanner".
3. Le plugin apparaît dans le navigateur : Plug-ins > VST3 > Brume Audio > Brume.

MAC
1. Décompresser Brume-macOS.zip (double-clic). Un dossier "Brume" apparaît.
2. Débloquer les fichiers (macOS bloque les apps non signées par Apple). Ouvrir le Terminal et taper,
   en adaptant le chemin si le dossier n'est pas dans Téléchargements :
   xattr -dr com.apple.quarantine ~/Downloads/Brume
3. Application autonome (pour Traktor) : glisser Brume.app dans le dossier Applications.
4. Plugins (pour Ableton) :
   - "Brume.vst3"      dans  /Bibliothèque/Audio/Plug-Ins/VST3/
   - "Brume.component" dans  /Bibliothèque/Audio/Plug-Ins/Components/
   Puis dans Ableton : Préférences > Plug-ins > activer "Utiliser les dossiers système VST3"
   et "Utiliser les Audio Units", puis "Rescanner".

UTILISATION
- Poser Brume sur une piste audio, un retour (mettre le switch sur WET) ou le Master.
- ON / OFF : allume ou éteint l'effet. À l'arrêt, la queue de réverbe et le bruit
  s'éteignent naturellement selon LENGTH.
- TREMOLO : fait pulser le bruit (NOISE). À zéro : pas de trémolo.
- TAP : taper le tempo du trémolo (un cycle par frappe).
- REC : enregistre ce qui sort de Brume (avec l'effet) en WAV dans Musique/Brume.
  Utile avec Traktor, dont l'enregistreur capte le son avant Brume.
- Tous les boutons sont automatisables dans Ableton (y compris On/Off).
- MIDI LEARN : cliquer sur le bouton MIDI en bas à droite, cliquer sur un contrôle de la pédale,
  puis tourner ou appuyer sur le contrôle voulu de votre contrôleur. Clic droit = supprimer le lien.
  Dans la version autonome, activer d'abord le contrôleur dans Options > Audio/MIDI Settings.
- TRAKTOR KONTROL F1 : l'appli autonome lit la F1 directement en USB, même quand Traktor l'utilise.
  Laisser la F1 en mode Traktor (pas en MIDI). En bas de Brume : "F1 read directly over USB" = OK.
  Ensuite MIDI learn comme d'habitude (les contrôles s'appellent F1 PAD 1, F1 KNOB 2, etc.).
  Attention : un contrôle de la F1 agit à la fois dans Traktor et dans Brume.
- Double-clic sur un bouton : valeur par défaut. Maj + glisser : réglage fin.

SYNCHRO AVEC TRAKTOR (trémolo calé sur le tempo des morceaux)
1. Traktor > Préférences > Controller Manager > Add... > Generic MIDI.
   Out-Port : "Traktor Virtual Output"   In-Port : None
2. Traktor > Préférences > External Sync : choisir EXT et cocher "Enable MIDI Clock".
3. Dans le panneau Master Clock de Traktor (icône métronome), cliquer sur play/pause pour envoyer l'horloge.
4. Dans Brume : Options > Audio/MIDI Settings > cocher "Traktor Virtual Output" dans les entrées MIDI.
Brume affiche alors un badge "SYNC 124.0 1/8" près de TEMPO : le bouton TEMPO choisit la division
(1 bar, 1/2, 1/4, 1/4T, 1/8, 1/8T, 1/16, 1/16T, 1/32, 1/64) et le trémolo repart sur chaque temps.
Sans horloge, TEMPO et TAP reviennent en mode libre (Hz). Dans Ableton, Brume suit le tempo du projet.

Une version autonome (Brume.exe / Brume.app) est fournie pour tester sans Ableton.

================================
BRUME STATION - l'appli de performance pour la Traktor Kontrol F1
================================
INSTALLATION (Mac) : glisser "Brume Station.app" dans Applications (même archive que Brume,
même commande xattr). Ensuite, les mises à jour de l'une mettent aussi l'autre à jour.
Pour Ableton : "Brume Station.vst3" / "Brume Station.component" comme pour Brume (c'est un instrument).

LA F1 ENTIÈREMENT POUR BRUME STATION (pads en couleur, écran)
Traktor > Préférences > Controller Manager : supprimer (ou désactiver) l'appareil "Traktor Kontrol F1".
Traktor reste piloté par la X1 et la Z1. En haut à droite de Brume Station : "F1 CONNECTED".

FONCTIONNEMENT : tout est expliqué dans l'app (bouton "?" en bas à droite = WIKI).
En bref : SHIFT + pad 1 à 5 choisit le programme (BRUME, ROLL, PATTERNS, PAD, FX), qui prend alors
les 4 boutons rotatifs, les 16 pads et l'encodeur. Les 4 faders (volumes) et les 4 STOP (marche/arrêt)
restent fixes. TYPE = DROP, CAPTURE = HOLD (roulements verrouillés), SIZE = programme suivant.

SYNCHRO TRAKTOR : comme pour Brume (Traktor Virtual Output + horloge MIDI), puis dans Brume Station :
Options > Audio/MIDI Settings > cocher "Traktor Virtual Output". Sortie audio : vers Traktor via BlackHole
(deck en Live Input) ou directement sur la sortie de votre carte son.
